Virtual AC3 Encoder - Quick start
=================================

What it does: encodes your PC's surround audio to AC3 (Dolby Digital) in real time and
sends it over the optical (Toslink / S-PDIF) output to your AV receiver -- software
"Dolby Digital Live" / "DTS Connect"-style.

Requirements
------------
1. A virtual audio device to capture surround audio. Install VB-CABLE (free):
       https://vb-audio.com/Cable/
   After installing + rebooting, open Windows Sound settings:
     - Set "CABLE Input (VB-Audio Virtual Cable)" as the DEFAULT playback device.
     - Right-click it > Configure Speakers > 5.1 Surround.

2. An optical (S-PDIF / Toslink) output that supports AC3 / Dolby Digital passthrough,
   connected to your receiver's optical input.

How it runs
-----------
The engine auto-starts hidden at logon and restarts itself if it stops. It reads its
settings from  virtual-ac3-encoder.conf  (in this folder).

The default config captures "CABLE Output" and sends AC3 to the first S/PDIF output it
finds. If you have more than one optical output, use the Start Menu > "Edit config"
shortcut and set, for example:
       out=Realtek Digital Output
(use the exact name shown by:  engine.exe --list)

Then switch your receiver to the matching optical input -- it should display Dolby Digital.

Handy commands (open a terminal in this folder)
-----------------------------------------------
       engine.exe --list      list audio input/output devices
       engine.exe --probe     show which outputs accept AC3 passthrough
       engine.exe --version
